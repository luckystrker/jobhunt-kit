# Job Search — план шаблона

Статус: первый этап шаблона реализован и проверен локально. Это универсальный шаблон, без профиля владельца,
реальных поисков, откликов и включённых регулярных задач.

## Согласованный результат

1. Самодостаточный пакет скиллов для Codex и Claude Code; Hirify CLI — фиксированная
   npm-зависимость, авторизация отдельно. Без приложения, сервера и интерфейса.
2. Инициализация пустого локального профиля: резюме, анкета, поисковые предпочтения,
   подтверждённые факты и банк ответов. Никаких заранее выбранных стран или профессий.
3. Проверка резюме по первичным источникам: факты, читаемость, риски парсинга,
   соответствие целевой роли. Никакого выдуманного универсального ATS-балла.
4. Поиск через Hirify до пяти новых подходящих вакансий за запуск с конечным бюджетом.
   Полные описания, объяснимое сопоставление, дедупликация и история всех просмотров.
5. Подготовка письма и ответов. По умолчанию отдельное согласование каждого отклика;
   опциональное ограниченное разрешение автоотправки. На первом этапе отправка только
   через Hirify, внешние формы — материалы и действие пользователя.
6. SQLite — история и статусы; Markdown — профиль, материалы и производные отчёты.
   Журнал намерения перед отправкой; неопределённый результат не повторять вслепую.
7. Шаблон задания для расписания, без создания расписания при установке.
8. Проверка на вымышленных данных, в отдельной временной папке.

## Критерии готовности

- Пустой профиль не допускает реального поиска или отклика.
- Повторная вакансия не создаёт второй отклик; повторный импорт не сбрасывает статус.
- Изменение профиля/письма делает старое согласование недействительным.
- Автоотправка по умолчанию выключена; ограничена сроком, профилем и числом попыток.
- Внешняя вакансия не проходит в отправку через Hirify.
- История сохраняется после перезапуска; отчёт объясняет причины и следующий шаг.
- Пакет не содержит персональных данных, ключей, локальной базы или зависимостей.
- Инструкции и проверки упаковки доступны; непроверенные live-сценарии названы явно.

Подробности реализации и фактическая проверка: `VERIFICATION.md`.

## Установка через npx

Дополнительный этап реализован: CLI `job-search init <directory>`, полная упаковка
шаблона и Hirify CLI, повторная установка без перезаписи данных. npm-архив проверен
реальным запуском npx. Распространение — через публичный GitHub; npm registry не требуется.

## Команды рабочих сценариев (0.2)

Этап реализован: детерминированные операции пяти скиллов вынесены в команды CLI.
Профиль: init/show/check/save/confirm. Резюме: import/check и пакет для проверки
агентом. Поиск: подготовка контекста, журнал запуска и результатов. Отклики:
prepare/preview/export/approve/begin/send/finish/resolve. Трекинг: list/show/status,
history/report. Дополнительно doctor и генерация задания schedule без включения расписания.
Проверки только с вымышленными данными; смысловая оценка и live-вызовы не подменяются
локальными тестами. Короткий npx доступен внутри установленной рабочей папки.
