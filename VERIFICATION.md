# Проверка шаблона

Дата: 2026-09-08. Среда: Windows, Node.js 24.14.1.
Проверяется универсальный шаблон, не реальный поиск кандидата.

## Выполнено

- `npm test`: 27 успешных offline-тестов, включая 4 проверки установщика, 10 проверок команд и 13 проверок локального трекера и отправляющей оболочки
  с подменённым транспортом. Проверены пустой профиль, повторная инициализация,
  дедупликация URL, сохранение статуса, необходимость полного текста, индивидуальное
  согласование, изменение профиля/письма/байтов резюме, внешний маршрут, дневной предел,
  неизвестные условия, истечение/отзыв auto, однократный вызов транспорта, тайм-аут,
  ручное разрешение неопределённости и чтение отчёта из нового процесса.
- `npm run check`: manifest/JSON, 5 скиллов, ссылки внутри пакета, пустой шаблон профиля,
  выключенный auto и фиксированная зависимость Hirify.
- Штатный `validate_plugin.py`: manifest Codex и структура плагина прошли проверку.
- Штатный `quick_validate.py`: все 5 скиллов прошли проверку (UTF-8).
- `claude plugin validate plugins/job-search`: manifest Claude Code прошёл проверку.
- На этапе 0.1 проверен переносимый setup: пакет скопирован в отдельную `.tmp/portable-plugin`, выполнен
  setup с установкой CLI в `.tmp/portable-data/runtime`; установлена одна зависимость.
  Проверено, что wrapper выбирает этот runtime и профиль остаётся неподтверждённым.
- Рекомендации сверены с первичными источниками: Greenhouse, Harvard, CareerOneStop;
  ссылки встроены в руководства. Упаковка сверена с документацией платформ и локальным CLI.

Вспомогательный PyYAML для штатных валидаторов установлен только в игнорируемую
временную папку. Он не является зависимостью шаблона. Для runtime достаточно Node.js.

## Установщик npx

- `npm pack` создаёт архив с явно ограниченным составом: 52 файла, без локальных
  данных, node_modules, .git и временных результатов.
- Реальная команда `npx --yes --package <локальный-архив.tgz> job-search init <папка>`
  установила шаблон в новую папку с пробелом в имени и установила hirify-cli 0.4.5.
- Повтор этой команды скопировал 0 файлов и сохранил вымышленный файл в local/.
- Проверки установщика: полная установка без создания личного профиля; идемпотентный
  повтор с сохранением данных; конфликтующий файл блокирует копирование до изменений.
- Root package-lock и .gitignore восстанавливаются из installer-assets; проверка
  пакета контролирует совпадение этих копий с оригиналами.
- Установщик не вызывает login, account, search или apply и не настраивает расписание.

## Команды 0.2

- Проверены профиль и его подтверждение, неизменяемая копия резюме, сохранение ручной
  проверки, контекст поиска, журнал запусков, экспорт отклика, статусы и задание расписания.
- Извлечение текста PDF и DOCX проверено на созданных тестом вымышленных документах;
  повреждённый PDF не получает успешный статус. TXT проверен отдельным сценарием.
- `resume` не объявляет документ готовым автоматически: визуальная проверка,
  достоверность фактов и решение агента остаются отдельными шагами.
- Короткие команды `npx --no --offline job-search doctor`, `profile init`, `resume`
  и `report` запущены в установленной папке с пробелом в имени; проверены созданные файлы.
- Регрессия запуска CLI через ссылку npm exec покрыта отдельным тестом:
  успешный код выхода без JSON не считается успешным запуском.
- `search` создаёт контекст для скилла, а `schedule` — текст задания. Эти команды
  сами не выполняют live-поиск и не создают расписание.

## Границы доказательств

- Реальный аккаунт Hirify не читался; поиск, reveal, apply, login и изменение настроек
  не выполнялись. Проверка реального формата ответов при отправке остаётся задачей
  первого пользовательского запуска; скилл не должен угадывать успешный результат.
- Реальное резюме не получено и не оценивалось. Парсинг/вёрстка конкретного PDF/DOCX
  и качество рекомендаций конкретному кандидату не проверены.
- Плагин не устанавливался в пользовательский аккаунт Codex/Claude Code. Валидность
  manifest не доказывает автообнаружение скиллов в новой сессии конкретной версии приложения.
- Расписание не создано. Периодичность, часовой пояс и режим выбирает будущий пользователь.
- Ранжирование и контроль количества найденных вакансий выполняются агентом по
  инструкции, а не автономным поисковым движком. Локальные тесты не измеряют качество
  матчей и писем реальной модели. Истинность фактов и согласий требует честной работы агента.
- SQLite и отправка Hirify не имеют общей транзакции. После сбоя возможен неизвестный
  результат; повтор блокируется и требует разбора. Автоповторы не реализованы.

## Как повторить

```powershell
npm ci --ignore-scripts
npm test
npm run check
claude plugin validate plugins/job-search
```

Штатные валидаторы Codex находятся в установленном skill-creator/plugin-creator,
поэтому не копируются в шаблон. Если они доступны, запускать их с Python UTF-8 и PyYAML.
