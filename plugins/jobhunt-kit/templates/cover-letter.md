# Черновик сопроводительного письма

Этот шаблон задаёт структуру; его нельзя отправлять с незаполненными полями.

1. Обращение, если адресат достоверно известен, и название роли.
2. Почему задача интересна кандидату — из его слов и проверенного описания вакансии.
3. Один-два подтверждённых примера: задача → действие → результат, связанные с требованиями.
4. Короткое приглашение обсудить роль. Доступность/контакт только если это нужно.

Отдельно от отправляемого текста сохранить:

- Для каждого фактического утверждения — evidence ID из profile.json.
- Неизвестные ответы и вопросы работодателю.
- Язык, выбранный профиль Hirify и точный способ отправки.

Для CLI хранить только текст письма в поле cover_letter файла draft.json.
Не включать в письмо внутренние оценки, evidence ID и служебные пояснения.
